# NEON ORBIT — Interactive Portfolio

크리에이티브 프론트엔드 개발자 포트폴리오를 위한 인터랙티브 원페이지입니다.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Highlights

- 마우스 반응형 궤도 오브젝트와 파티클 필드
- 프로젝트별 CSS 아트워크와 반응형 레이아웃
- 스크롤 리빌, 마그네틱 CTA, 커스텀 커서
- 키보드 포커스, 스킵 링크, `prefers-reduced-motion` 대응
- 모바일/태블릿/데스크톱 최적화

프로젝트 내용, 이메일, GitHub 링크는 `src/App.tsx`에서 실제 정보로 교체할 수 있습니다.
